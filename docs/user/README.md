# OpenCraft user guide

OpenCraft operates the VSD StreamDock N4 Pro controller on a Mac. You do not
need the vendor software VSD Craft.

Read the first two chapters in their order. Then use the other chapters when
you need them.

| Chapter | Contents |
|---|---|
| 1. [Install and first start](install.md) | Install OpenCraft, start it for the first time with a starter profile and ready profiles, the parts of the window, give the Accessibility permission (only for three action kinds), remove OpenCraft |
| 2. [Configure a key](first-key.md) | The main procedure: select a key, set its title, fill, icon, and action, and push the key. Also undo, copy and paste, the command palette (Command-K), and the keyboard. |
| 3. [Actions](actions.md) | The library, drag and drop, the test of an action, each action kind and its settings, the toggle, and the sequence |
| 4. [Knobs, touch bar, pages, and profiles](controls.md) | The other controls, more pages, folders of keys, the background of a page, more profiles, the profile settings, export and import, and the device settings |
| 5. [Operation in the background](background.md) | The menu bar item, the Settings window, the Dock icon, the start at login, and the files of OpenCraft |
| 6. [Faults and corrections](faults.md) | What to do when something does not operate, and the limits of OpenCraft |
| 7. [Privacy](privacy.md) | No network, no telemetry, and no account. OpenCraft stores your files on this Mac. |

OpenCraft itself does not use the network. See [Privacy](privacy.md).

## Words in this guide

| Word | Meaning |
|---|---|
| Device | The StreamDock controller that is connected to the computer |
| Control | A part of the device that you operate: a key, a knob, a bar panel, or the touch bar |
| Key face | The display on a key |
| Title | The text on a key face or a bar panel |
| Fill | The colour of a key face or a bar panel |
| Touch bar | The long touch display between the keys and the knobs |
| Bar panel | One of the four parts of the touch bar. Each bar panel has its own image. |
| Gesture | One thing that you do to a control, for example push a key, turn a knob, or swipe on the touch bar |
| Action | The work that OpenCraft does for a gesture, for example open a URL |
| Binding | The link from one gesture on one control to one action |
| Page | One full set of key faces, bar panels, and bindings. The device shows one page at a time. |
| Folder | A set of keys outside the page cycle. The knobs, the touch bar, and the background stay those of the page. |
| Profile | A named set of pages |
| Background | The image or the colour of a page, on all of the display behind the key faces and the bar panels |
| Inspector | The tab of the right panel that shows the settings of the selected control, page, or device |
| Library | The tab of the right panel that shows all action kinds |
| Command palette | The search window of Command-K. It finds action kinds, controls, pages, profiles, and commands. |
| Settings window | The window of Command-comma with the options of OpenCraft |
