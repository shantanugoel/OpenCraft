# Triage labels

The skills use five triage roles. This table gives the label in this
repository for each role.

| Role in mattpocock/skills | Label in this repository | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | The owner must examine this issue |
| `needs-info` | `needs-info` | The reporter must give more information |
| `ready-for-agent` | `ready-for-agent` | The issue is complete. An agent can do it with no help |
| `ready-for-human` | `ready-for-human` | A person must do this issue |
| `wontfix` | `wontfix` | Nobody will do this issue |

When a skill names a role, use the label from this table.

These labels are for triage only. The labels for the roadmap, the phases, and
the tasks are in [CONTRIBUTING.md](../CONTRIBUTING.md#how-the-issues-are-organized).
